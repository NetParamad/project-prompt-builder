# Next.js single client app with zustand

We build a single Next.js App Router + TypeScript + Tailwind + shadcn/ui app with all state client-side in a zustand persisted store, no backend or database, deployable to Vercel as a static-ish app. Chosen over a server-backed or multi-package setup because the MVP is a configurator with deterministic local prompt generation and no shared server state.
